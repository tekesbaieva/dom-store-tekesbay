# DOM Store Application

## Как открыть?
1. Клонируйте репозиторий или скачайте его в виде ZIP-архива.
2. Откройте файл `index.html` в любом браузере.

## Обработанные события и их назначение:
- **`submit` (на форме):** Предотвращает стандартное поведение перезагрузки страницы при добавлении товара и запускает DOM-валидацию введенных данных.
- **`click` (через делегирование):** Один общий слушатель событий на списке товаров эффективно обрабатывает нажатия на кнопку удаления любого элемента.
- **`input` (через делегирование):** При изменении количества (qty) в поле ввода мгновенно пересчитывает и обновляет `live total` без перезагрузки страницы.
